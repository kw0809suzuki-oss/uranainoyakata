# 将来の日本語タロット辞典の保存場所

今回は保存場所だけを用意しています。日本語の辞典本文・翻訳・要約・カード別解説は作成していません。

原文は `data/sources/tarot-rws-dataset/v1.1.0/upstream/` に保存し、この場所へコピー・上書きしません。取得情報は同バージョンの `provenance.json`、検証情報は `data/source-audits/tarot-rws-dataset/v1.1.0/` を参照してください。

将来ここに日本語辞典を作る際は、原文と区別し、使用したデータのバージョン・card_id・source_id・参照節を記録します。翻訳・編集の範囲と変更点、StarTarotへの帰属、CC BY 4.0へのリンクも明示する必要があります。現段階では辞典形式やアプリとの対応付けは決めていません。

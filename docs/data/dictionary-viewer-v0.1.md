# 日本語タロット辞典 閲覧・検証環境 v0.1

## 基準と範囲

2026-10-24に最新mainと指定コミット `ed9ee30232b20310888eb41d579ce38b0b6a741d` の一致を確認し、fast-forwardで取り込んだ。`data/dictionary/ja/cards/*.json` の78枚を正本として使う読取専用画面。

原典・辞典内容・スキーマ・既存Python検証器・既存の検証結果は変更していない。占い側の78枚・正逆・抽選・10枚配置・カード編集・localStorage・AI処理は変更せず、入口のリンクだけを追加した。辞典の意味を占い用データに置き換えていない。

## 利用方法

既存の独立起動環境で `pnpm dev`、または `pnpm build` の後に `pnpm start`。占い画面の「辞典を読む」から `/dictionary` に入る。詳細の例は `/dictionary/00-fool`、`/dictionary/cups--two-of-cups?position=reversed`。

一覧は78枚、大/小アルカナ、スート、日本語・英語のカード名検索。検索と分類はURLに残り、詳細の「一覧へ戻る」で維持する。正逆はタブ、左右キー・Home/Endで切り替えられる。

詳細では以下を分離する。

- 固定版の原典レコード・書誌・出典ID・節・JSON Pointer・原典データへのリンク。
- 基本/追加それぞれの英語全文と暫定訳、英日対照の全単位と翻訳状態。
- 今回の要約候補、正逆の解釈候補、原典にないapplication、補足の境界と理由。
- 根拠IDから、対象となる向きの英日対照単位へのリンク。
- 正逆・追加欄すべての曖昧さ、未解決の問い、解決記録、人間の校閲・歴史資料照合等の状態。
- 版・ライセンス・帰属、正本JSONの全項目（構造に未知の追加情報があっても削除しない）。

要約候補を全意味と扱わず、相反する意味も全文に残す。星の正位置の「喪失…別の読みでは希望…」、カップ2逆位置の `Passion.` と§4由来、ワンド6枚の追加逆位置null等を維持。独立した人物条件/矛盾一覧フィールドは正本にないので、作り足さず、原文・訳文・既存注記を読む構成にした。

## 読込と破損検出

`GET /_api/dictionary` がJSONファイルを読み取り、78件・一意ID・連番・必須構造を検査する。原典JSONLと分類/英語名/ID/意味全文/参照節/ハッシュを比較し、英日対照の原文語句網羅・日本語単位保持・単位ID・根拠参照も検査する。これは内容の正しさを保証する意味検証ではない。既存Python検証器を置き換えていない。

読み込めない、不整合がある、通信やJSONが壊れる等のときは、部分的な辞典を正常な78枚と見せず、明示エラーと再試行を表示する。不在はavailability/statusとnullで、未照合や校閲待ちはその状態で示す。情報が未登録の場合は不存在の証明とせず、未登録/未確認とする。

## 未解決・未検証

- 忠実訳は暫定のまま。人間の独立校閲pending、歴史資料の個別ページ照合not_performed、解決記録nullは変更していない。語義や相反する意味をこの開発で確定していない。

- AI読み解きはローカルHTTPフィクスチャを使った通信/画面テスト。実サービスの認証・モデル応答品質・Floot実行は今回も未検証。
- TypeScript全ソースの型検査、Firefox/WebKit、実機の全端末や支援技術による検証は実施していない。ビルドは型検査の代用ではない。
- 原典と辞典のJSON自体は新たに静的配信領域へ複製せず、APIは正本をサーバーで読む。本番配備でもdata以下の正本・原典が必要。
